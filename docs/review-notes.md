# App Review Notes — JawEase: TMJ Relief

Developer: Dan Johnson
Contact: dan@listinglab.pro

JawEase helps people with TMJ (temporomandibular joint) pain through daily guided jaw exercises and pain tracking.

## How to test:

1. Launch the app — onboarding begins automatically
2. Select 2-3 symptoms (e.g. Jaw pain, Teeth grinding)
3. Set baseline pain level by dragging the orb up/down
4. Set a reminder time
5. Enter any email address (e.g. test@example.com)
6. Paywall appears — dismiss via X to enter Preview Mode, or start free trial
7. Today tab: tap "Start Routine" for guided exercises
8. Exercise flow: countdown, timer, rest periods, completion with pain log
9. Exercises tab: browse 8 exercises, filter by category, expand for details
10. Progress tab: pain trend, streak, calendar heatmap, insights
11. Settings: change preferences, toggle reminders, export report, manage subscription

## Notes:
- No login required — all data stored locally on device
- Email used only for progress reports via Resend (transactional email)
- No external AI services — all insights computed on-device
- Supports light and dark mode
- Restore Purchases available in Settings
